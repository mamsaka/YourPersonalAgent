# open

Загрузка изображения в запрос к модели (мультимодальность). Читает файл с диска, кодирует в Base64 data URL и возвращает блок контента типа image_url (OpenAI-compatible vision format), который модель может увидеть в диалоге.

## Instructions

# Навык open — мультимодальная загрузка изображений

## Назначение
Позволяет агенту загрузить изображение с диска и передать его в запрос к модели, чтобы модель видела изображениеcontents в диалоге (мультимодальность / vision). Это НЕ открытие файла в просмотрщике — это подготовка изображения для отправки модели.

## Когда использовать
- Пользователь просит посмотреть на картинку, описать изображение, проанализировать скриншот, диаграмму, фото документа и т.п.
- Нужно, чтобы модель "увидела" изображение в контексте разговора.

## Параметры
- `path` (обязательный) — абсолютный или относительный путь к изображению. Относительные пути разрешаются относительно папки workspace.
- `detail` (опциональный) — уровень детализации изображения: `low`, `high` или `auto` (по умолчанию `auto`).

## Формат результата
Тулза возвращает словарь с полями:
- `status`: "uploaded"
- `path`: абсолютный путь к файлу
- `mime_type`: MIME-тип изображения (image/png, image/jpeg и т.п.)
- `detail`: уровень детализации
- `data_url`: Base64 data URL изображения
- `content`: список с двумя элементами — текстовый блок `[Изображение: имя]` и блок `image_url` с data URL

## Как агенту использовать
1. Вызови тулзу `open` с путём к изображению.
2. Полученный `content` (список с image_url) добавь к пользовательскому сообщению, которое отправляешь модели.
3. Модель получит изображение вместе с текстом и сможет его прокомментировать.

## Пример вызова
```
open(path="C:/Users/Ramil/Desktop/photo.jpg", detail="auto")
```

## Подтверждение
Загрузка файлов за пределами папки workspace требует подтверждения пользователя.
