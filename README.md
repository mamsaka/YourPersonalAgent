# YourPersonalAgent

Персональный ИИ-агент для рабочего стола на Python + Tkinter. Работает с любой моделью OpenRouter, видит ваш компьютер через инструменты, помнит важное между чатами и умеет создавать собственные навыки и Python-инструменты.

> Это **не песочница**. Агент действует с правами вашего пользователя, поэтому опасные операции подтверждаются в интерфейсе.

## Возможности

- **Любые модели OpenRouter** — не только бесплатные. Поиск по названию, отдельный список моделей с цветовой пометкой (`:free` — зелёный, платные — красный).
- **Потоковый ответ** — текст и рассуждения модели появляются по мере генерации. Reasoning показывается отдельной раскрывающейся карточкой.
- **Расход под контролем** — внизу чата счётчики: запросы, входной контекст, токены и потраченные деньги (по данным OpenRouter). В подсказке — общий итог за всё время.
- **Чаты и история** — несколько сессий, поиск по чатам, переименование, удаление, откат к любому сообщению и повторная генерация ответа.
- **Долговременная память** — общая для всех чатов, с поиском и тегами.
- **Навыки** — повторяемые инструкции в `skills/*/SKILL.md`; агент видит список и читает нужный навык сам.
- **Свои инструменты** — агент может написать Python-инструмент (`create_python_tool`), и тот сразу появится в реестре.
- **Терминалы и браузер** — постоянные сессии: рабочая папка и переменные окружения терминала, открытые вкладки браузера сохраняются между вызовами.
- **Подтверждения** — удаление, запись вне `workspace/`, команды, создание инструментов, ввод текста на сайтах. Переключатель «Подтверждать действия» в настройках.
- **Темы и горячие клавиши** — светлая/тёмная тема, Ctrl+C/V/X/A/Z/Y работают на любой раскладке.
- **Характер агента** — готовые стили общения (дружелюбный, краткий, наставник, саркастичный) или свой текст.
- **Всё помнит между запусками** — ключ, модель, последний чат, тема, подтверждения и размер окна хранятся в `.env`.

## Быстрый старт

Нужен Python 3.11+ и ключ [OpenRouter](https://openrouter.ai/keys).

```powershell
git clone https://github.com/mamsaka/YourPersonalAgent.git
cd YourPersonalAgent

python -m venv .venv
.\.venv\Scripts\Activate.ps1

pip install -r requirements.txt
```

Необязательные зависимости (браузер и эмуляция мыши/клавиатуры):

```powershell
pip install -r requirements-optional.txt
```

Создайте `.env` из примера и впишите ключ:

```powershell
Copy-Item .env.example .env
notepad .env
```

```env
OPENROUTER_API_KEY=sk-or-v1-...
```

Запуск:

```powershell
python app.py
```

Ключ и модель также можно задать в окне **Настройки** — они сохранятся в `.env`.

## Настройки `.env`

Обязательный:

| Ключ | Значение |
|------|----------|
| `OPENROUTER_API_KEY` | API-ключ OpenRouter |

Приложение само дописывает и обновляет:

| Ключ | Что хранит |
|------|------------|
| `OPENROUTER_MODEL` | последняя выбранная модель |
| `AGENT_LAST_SESSION` | id последнего активного чата |
| `AGENT_THEME` | `dark` или `light` |
| `AGENT_CONFIRM_DANGEROUS` | подтверждать ли опасные действия |
| `AGENT_PERSONA` | характер агента |
| `AGENT_WINDOW_GEOMETRY` | размер и позиция окна, например `1240x800+100+50` |

Дополнительные (обычно менять не нужно):

| Ключ | По умолчанию | Назначение |
|------|--------------|------------|
| `OPENROUTER_BASE_URL` | `https://openrouter.ai/api/v1` | адрес API |
| `OPENROUTER_MAX_TOOL_ROUNDS` | `40` | лимит шагов «модель → инструмент → модель» (`0` — без лимита) |
| `OPENROUTER_MAX_TOKENS` | `8192` | максимум токенов в ответе |
| `OPENROUTER_MAX_HISTORY` | `24` | сколько последних обращений пользователя отправлять модели |
| `OPENROUTER_TIMEOUT` | `90` | таймаут запроса, секунды |
| `OPENROUTER_STREAM` | `true` | потоковый вывод |
| `OPENROUTER_VERIFY_SSL` | `true` | проверка SSL-сертификата |

`_write_env_file` обновляет только нужные строки: комментарии и ваши собственные переменные не затрагиваются. Файл `.env` не попадает в git.

## Характер агента

Кнопка **«✎ Характер»** в боковой панели задаёт стиль общения агента — он добавляется в системный промпт и влияет только на манеру речи, не отменяя правила безопасности.

Есть готовые заготовки:

| Заготовка | Стиль |
|-----------|-------|
| Нейтральный | Уравновешенный и деловой, только по сути |
| Дружелюбный | Тёплый и приветливый, поддерживающий |
| Краткий | Предельно сжатые ответы без вступлений |
| Наставник | Объясняет «почему» и «как», подсказывает путь |
| Саркастичный | Ироничный, с едкими шутками, но без оскорблений |

Также можно выбрать **«Свой вариант»** и описать характер словами (до 10 000 символов). Выбор сохраняется в `.env` как `AGENT_PERSONA` и применяется со следующего запроса.

В окне видно ровно тот текст, который уйдёт модели: у готовых характеров это подробная инструкция по стилю (тон, обращения, что допустимо и что запрещено), у своего варианта — ваш текст.

## Управление

| Действие | Клавиши |
|----------|---------|
| Отправить | `Enter` |
| Новая строка | `Shift+Enter` |
| Отправить | `Ctrl+Enter` |
| Остановить агента | `Esc` |
| Новый чат | `Ctrl+N` |
| Поиск по чатам | `Ctrl+F` |
| Настройки | `Ctrl+,` |
| Переименовать чат | `F2` или двойной клик |
| Удалить чат | `Delete` |

Правый клик по сообщению: откат истории к этому запросу и его редактирование, а для ответа — повторная генерация с исходного запроса.

## Инструменты

Встроенные инструменты имеют постоянные ID (видны в диалоге «Инструменты»).

| ID | Инструмент | Что делает | Подтверждение |
|----|------------|------------|---------------|
| 1 | `list_files` | список файлов и папок | — |
| 2 | `read_file` | чтение UTF-8 файла с нумерацией строк и постранично | — |
| 3 | `write_file` | создание/перезапись файла | вне `workspace/` |
| 4 | `edit_file` | точечная замена фрагмента | вне `workspace/` |
| 5 | `delete_path` | удаление файла или папки | да |
| 6 | `remember` | запись в долговременную память | — |
| 7 | `forget` | удаление записи из памяти | — |
| 8 | `search_memory` | поиск по памяти | — |
| 9 | `list_skills` | список навыков | — |
| 10 | `read_skill` | чтение `SKILL.md` | — |
| 11 | `create_skill` | создание навыка | — |
| 12 | `create_python_tool` | создание и установка Python-инструмента | да |
| 13 | `get_local_time` | локальные дата и время | — |
| 14 | `use_cmd` | постоянный терминал: создать, выполнить, прочитать вывод | выполнение команд |
| 15 | `use_browser` | постоянный браузер Selenium: открыть сайт, получить текст, клик, ввод | ввод текста |
| 16 | `open` | загрузка изображения для мультимодальной модели | вне `workspace/` |

Относительные пути считаются от `workspace/`. Абсолютные могут указывать куда угодно — с подтверждением для опасных операций.

## Данные и приватность

```
data/agent.sqlite3      чаты, сообщения, память, счётчики расхода
data/backups/           резервные копии файлов перед перезаписью
data/ui_settings.json   старые настройки интерфейса (мигрируются в .env)
workspace/              рабочая папка агента
skills/                 ваши навыки
tools/generated/        сгенерированные Python-инструменты
```

- `data/`, `workspace/`, `tools/` и `.env` исключены из git.
- История и память хранятся локально в SQLite и отправляются только выбранной модели через OpenRouter.
- Ключ хранится в `.env` с ограниченными правами доступа; не публикуйте этот файл.

## Безопасность

Проект сознательно даёт агенту широкие права. Защита построена на трёх уровнях:

1. **Шлюз подтверждений** — опасные действия не выполняются без вашего согласия; часть из них можно разрешить на всю сессию.
2. **Системный промпт** — содержимое файлов, сайтов и результаты инструментов считаются данными, а не командами (смягчает prompt injection, но не гарантирует защиту).
3. **Резервные копии** — перезаписываемые файлы сохраняются в `data/backups/`.

Любой код, созданный и запущенный агентом после подтверждения, выполняется без ограничений. Не отключайте подтверждения, если не понимаете последствий.

Характер агента меняет только тон общения: он не может снять подтверждения или отключить правила безопасности.
